Dungeons II Keybinder

Choose which keys and mouse buttons do what in the WASD controller mod for Minecraft Dungeons II. The mod turns them into the game's controller buttons, shown next to each action. Save the settings file into the game folder and restart the game.

Where it goes
  1. Put the file in the game's Win64 folder. In CrossOver's default Steam bottle that is:
    ~/Library/Application Support/CrossOver/Bottles/Steam/drive_c/Program Files (x86)/Steam/steamapps/common/Minecraft Dungeons II/Dungeons/Binaries/Win64
    In Finder: Go › Go to Folder (⇧⌘G), paste.
  2. The mod reads wasd-mod.ini or wasd-mod.txt, whichever is newer, so a fresh save always wins.
  3. Restart the game.
