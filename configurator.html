Dungeons II Keybinder

Choose which keys and mouse buttons do what in the WASD controller mod for Minecraft Dungeons II. Fights always go through the mod's virtual controller; menus can use the game's own keyboard shortcuts or the controller. Save the settings file into the game folder and restart the game.

Where it goes
  1. Windows: run wasdmod-Windows.exe and click Load layout file. Or put the file in the game's Dungeons\Binaries\Win64 folder yourself.
  2. Mac: open the wasdmod app and choose Load a layout file. Or put it yourself in (CrossOver, default Steam bottle)
    ~/Library/Application Support/CrossOver/Bottles/Steam/drive_c/Program Files (x86)/Steam/steamapps/common/Minecraft Dungeons II/Dungeons/Binaries/Win64
    In Finder: Go › Go to Folder (⇧⌘G), paste.
  3. The file is default.txt or author.txt for an unchanged built-in layout, otherwise wasdmod-MMDDYY.txt. The mod uses the newest of them, so a fresh save always wins. Restart the game.
